# 过牌双敲桌音

`public/audio/check-knock.wav` 是为 BBPoker 原创合成的短促双敲桌音，
不是现场录音，也未提取任何扑克平台、视频或其他第三方素材。

声音模拟指节敲击有软垫的木质牌桌：两次触桌间隔约 139 ms，第二次稍轻；
采用带限冲击噪声与短促、非整数倍的阻尼共振。高频攻击被柔化，避免电子蜂鸣或尖锐点击。
它替代过牌语音，其他操作的语音素材保持不变。

## 复现

运行时使用 `public/check-knock.js` 在本地直接生成 AudioBuffer，无需下载声音文件，
不受首次动作时网络素材尚未载入的影响。试听 WAV 由同一个函数生成，没有第二套合成算法。
只需 Node.js，在项目目录运行：

```sh
node scripts/build-check-knock.mjs
```

固定随机种子使同一脚本可以重建音频。允许用 `--output /path/to/check-knock.wav`
输出试听文件。函数内部使用固定种子的 xorshift32 噪声；不需要网络、账号、密钥或第三方音频库。
运行 `node --test test/check-knock.test.js` 会逐采样对比 WAV 与运行时缓冲区。

## 产物校验

- PCM16，单声道，44,100 Hz，15,876 帧，360 ms。
- 31,796 字节；波形峰值 `0.8599853515625`，RMS `0.08492621605741749`。
- 无削波，首尾衰减；两次敲击共用一个声音文件，不会因异步调度改变节奏。
- SHA-256：`0107050785b555b7dad4aec6b1f556fa5ce69573a969eda33e8f833ccd550fb7`。

RMS 与当前已选筹码录音约 `0.079` 接近。最终听感还取决于桌面音效模块的播放增益、
设备扬声器和用户音量；过牌声应沿用音效静音、后台停止与动作去重控制。
