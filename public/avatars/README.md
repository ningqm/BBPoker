# BBPoker default avatars

Six original animal illustrations generated with the built-in image generation tool: fox, panda, cat, penguin, rabbit and dog. Each default image is 384 × 384 pixels. Users receive a random default; these are not unique per-account model generations.

Prompts and provenance: [Avatar generation](../../docs/avatar-generation.md).

Custom user uploads are private encrypted server data. They must never be added to this directory or repository.
