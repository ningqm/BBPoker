# 多牌桌与鱿鱼轮次

BBPoker 是朋友之间的积分游戏。以下为本项目明确约定的家规，并不宣称与 WPK、ClubGG 或其他平台逐项相同。

## 鱿鱼参与与离开

- 每轮开始时固定参与名单和每份积分 `unit`。每人预留 `(人数 − 1) × unit`，这些预留仍属于本人，不计输赢。
- 新朋友可以加入房间；本轮中途新落座的人等待下一轮，不插入已有轮次，也不补交当前轮次的罚分。
- 唯一主池赢家获得一个标记。重复获胜不叠加标记；平分主池、只赢边池以及未跟注筹码退回都不算获标。炸弹池的唯一主池赢家也适用。
- 主动离座或暂离在本手结束后生效，不取消已经参与的手牌。先按本手结果发放标记和正常结算，再处理退出；若当手赢到标记，退出时不会再视为未获标。仍未获标者主动退出当前鱿鱼轮，视为本轮失败：向固定名单中的其余每人支付一份积分，本轮立即结算。同手有多人申请退出时按申请顺序处理，一轮只结算一次。
- 已获标者可以离座或暂离，并保留本轮获分资格。之后的积分直接记回本人，不要求仍坐在结算手中。
- 只剩一人未获标时正常结算：该人支付 `(人数 − 1) × unit`，其余每人获得 `unit`。结算后返还剩余预留。
- 房间结束、自然到时，或者由于参与者离线、缺码或可参与人数不足而持续等待达到 90 秒后，由在线参与者主动结束本轮，采用部分结算：每位未获标者向每位已获标者支付一份积分；未使用的预留退回。没有获标者时，所有人的净变动为 0。等待原因改变、恢复连接或服务端重启后，重新观察宽限时间，避免用失真的离线时长判定。
- 单纯断网、切到微信或关闭页面不等于主动离座，不直接判负；重连继续使用原身份和原轮次。当前手仍按服务端行动时限推进。离线计时到达门槛只提供结束轮次的条件，不在后台自动扣罚。

例：5 人每份 2 BB，2 人已经获标，3 人尚未获标，房间到时。每位未获标者支付 4 BB，每位已获标者得到 6 BB，总变化为 0。若其中一位未获标者主动退出，则该人支付 8 BB，其余四人各得 2 BB，并结束本轮。

## 记录与筛选口径

每轮结算保存独立的 `squidSettlement` 流水，包含共享的 `roundSettlementId`、轮次、原因、结算时间及每人的净变动，包括净变动为 0 的参与者。预留的原额返还不重复计为盈利。若结算发生在一手结束时，该手也保留小游戏展示字段；统计按房间、结算编号和玩家去重，不能把手牌展示和独立流水相加两遍。

- 对局详情与总计包含该场全部已结算的鱿鱼变化，即使收款者已经离座，或未参加最后一手。对局日期筛选按对局开始时间筛选整场，与既有口径一致。
- 个人数据的日期筛选按独立鱿鱼流水的结算时间计算。跨日时，昨天打的手与今天结算的鱿鱼可以分属两个日期；不为手外结算增加虚假的手数、德州盈亏、入池机会或全下期望样本。
- 选择“最近 N 手”时，只统计所选实际手牌，以及明确属于这些手牌的鱿鱼结算；手外结算不计入这个手数范围。流水上的 `handId` 可能仅指向此前最后一手，不能据此把手外收入塞进旧手牌。
- 牌谱页面继续显示具体手牌产生的小游戏变化。手外变化在对局、个人数据和导出调整记录中体现。
- 旧版本只有 `miniChanges` 的历史继续读取，不要求重写存档，也不会补造不存在的结算编号。

## 多牌桌边界

登录后的大厅展示活动桌的基本信息。“公开加入”允许登录用户直接进入；“仅限邀请”只展示目录摘要，进入仍需原成员身份或有效邀请。邀请制不表示桌名在大厅隐藏，目录不会给出邀请凭证、成员列表、聊天、底牌或账目。

同一服务器按房间分别维护牌序、行动时钟、成员和消息；多桌不意味着同一账号可以同时入座多桌。一个账号可以查看已获准加入的其他房间，但当前座位必须按上面的本手和鱿鱼规则处理完，才能坐到另一桌。仅切换页面不会自动离座。满座时保留旁观身份；当前没有按先后顺序自动分配座位的候补队列。

等待中的房间和正在玩的房间都占用活动房间名额。当前部署保持单进程写入加密存档，不允许多个进程各自保存同一份文件；添加房间不改变底牌和历史的成员权限边界。

## 参考资料与证据边界

核对日期：2026-10-13。

- [ClubGG 官方 Squid Game Mode](https://help.clubgg.com/article/Table-Creation--Squid-Game-Mode)：浏览器实际读取到以 BB 配置罚分、按手数或时间触发和最少人数条件。该页没有说明中途加入、获标离桌、未获标退出或断线重连的完整细则。本项目的上述细则不能标为 ClubGG 官方规则。
- [Poker at Queenco 官方规则](https://pokeratqueenco.com/rules)：明确新玩家等待当前鱿鱼轮结束。它同时采用 8 人、7 个标记且可重复获标的变体；本项目仅参考等待下一轮的原则，不采用其整套多标记计分。
- [ClubGG 官方 Clubs Basics](https://help.clubgg.com/article/Clubs---Basics)：私人俱乐部通过 6 位 Club ID 或成员分享的链接加入；平台不直接分发 Club ID。此处证明的是“先加入私人社区，再看该社区牌桌”的产品方式，不代表 BBPoker 必须复制俱乐部、代理或审批层级。
- [PokerStars 官方 Home Games](https://www.pokerstars.com/help/articles/home-games-faq/)：通过俱乐部编号和邀请代码申请，管理者接受后显示在本人 Home Games 列表，可在俱乐部内创建牌桌。
- WPK 的可读取宣传页仅能证明其宣传好友桌与鱿鱼类玩法。本次未找到并独立核实 WPK 官方完整规则中的离桌、断线和结算细则；代理文章及自称官网的下载页不能填补这个证据缺口。
