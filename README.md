# BBPoker

BBPoker 是供朋友通过邀请同桌玩的德州积分游戏。此仓库包含可独立运行的网页和 Node.js 后端：全站同一时间一桌，2–9 人入座，手机和电脑浏览器连接同一个服务器。没有充值、提现、抽水或现金结算。

公开仓库：[ningqm/BBPoker](https://github.com/ningqm/BBPoker)。

当前源码版本为 **0.5.0**。线上网站是否使用此版本，应由部署者另行核验。

## 本机启动

需要 Node.js 22 或更高版本。网页和服务端没有第三方运行依赖，无需执行 `npm install`。

```sh
npm start
```

打开 [http://localhost:8787](http://localhost:8787)。注册账号和密码，私下保存找回码；创建牌桌并入座，通过“邀请”复制链接给朋友。至少两人入座后由房主开始发牌。`localhost` 仅指当前设备，异地联机需要部署统一的 HTTPS 网站，见 [部署说明](docs/deployment.md)。

首次启动会创建 `data/`，其中包含加密存档与密钥。**不要将数据目录、密钥、真实环境配置或导出的私人牌谱提交到仓库。**

## 功能

- 账号密码注册、登录、修改密码、找回码重置与会话撤销；可修改昵称、选择 12 枚内置头像，没有短信或邮箱服务。
- 邀请入桌、直接带入、补码、暂离、离座、转交房主和结束本场。带入以大盲数量（BB）配置，默认 20–200 BB，可设置无上限，无需审批。
- 无限注德州、主池/边池、平分和零头分配、未跟注退款；可选鱿鱼及单牌面炸弹池。蘑菇已移除，旧记录与退款保留。
- 常用盲注和时长预设，默认盲注 5 / 10、思考 15 秒、本场 1 小时。第一手开始计时，到期打完当前手后自动收桌，最后 5 分钟不新开小游戏。
- 默认每半小时重置 3 张时间牌，每张延长 30 秒，数量和时长可配置；服务器保存剩余时间牌和计时状态。
- 同桌文字聊天、快捷表情、轻量动效、断线重连和服务器行动倒计时；断线或重启不重置有效倒计时。
- 个人牌谱、收藏、逐步回放、JSON/TXT/CSV/PHH 导出与生涯统计。
- 实时、历史、回放及导出均按玩家身份过滤，其他人的未公开底牌不会通过正常接口下发。

详细说明：[玩法规则](docs/rules.md)、[账号](docs/accounts.md)、[聊天与回放](docs/social-replay.md)、[PHH 牌谱](docs/hand-history.md)。

## 发牌与隐私边界

洗牌使用 Node.js `crypto.randomInt` 与 Fisher–Yates；洗牌函数不读取账号、历史输赢或玩家画像。小游戏不改变牌序。服务器在每手开始固定牌序，并提供本人可见牌的承诺校验材料。

**仍需信任服务器及网页运行者。** 服务器进程知道完整牌序，拥有服务器文件和存档密钥的人可以解密数据。承诺核验只能检查可见牌是否符合承诺，不能证明初始抽样公平、线上程序与公开源码相同，或管理员无法查看底牌。本项目没有多方加密洗牌、零知识公平证明或第三方公平性认证。详见 [发牌与数据边界](docs/fairness.md)。

## 检查

```sh
npm run check
npm test
node scripts/verify-export.mjs --help
```

默认测试使用 Node 内置测试框架及独立临时数据，不连接正式站点，不需要安装原生客户端依赖。可选的 PokerKit 交叉验证只有显式设置独立 Python 解释器时才运行，步骤见 [PHH 牌谱说明](docs/hand-history.md)。

离线导出验证器可核验一份 BBPoker JSON 牌谱内的可见牌与承诺是否一致，不联网、不打印底牌；它不验证牌谱真实性、完整性或服务器是否公平。

本仓库公开测试代码；请以自己在对应版本上实际运行的结果为准。测试通过不是独立审计，也不能替代真实手机、异地网络和备份恢复验收。

## 目录

| 路径 | 内容 |
|---|---|
| `server.js`、`src/` | HTTP/SSE 服务、身份验证、牌局规则、洗牌、牌谱与加密存储 |
| `public/` | 完整网页界面与静态资源 |
| `test/` | 自动化功能、权限、结算和客户端回归测试 |
| `scripts/verify-export.mjs` | 离线牌谱承诺验证器 |
| `scripts/build-clients.mjs`、`apps/` | 测试使用的实验性桥接和资源构建代码，见 [范围说明](apps/README.md) |
| `docs/` | 玩法、隐私、账号与通用部署说明 |

## 部署与数据

支持直接运行 Node 或构建 Docker 镜像。必须只运行一个写入实例；当前每次操作保存整份加密存档，不支持多个进程共享写入。更新程序不应替换数据或密钥。程序、数据分目录不能防止磁盘损坏或误删，需要部署者另行配置服务器之外的私密备份并验证恢复。

仓库不包含线上账号、用户记录、环境配置、云资源标识或部署实录，也不包含正式 App 安装包。真实设备兼容性由部署者按实际使用环境验收。
