# 默认头像生成记录

这些原创动物插画使用 Codex 内置 image_gen 工具分别生成，并经过逐张视觉检查。它们作为一组预生成的默认头像供随机分配；不会为每个账号实时调用付费图像接口，也不表示头像在所有用户间唯一。

发布图片仅做等比例缩小和 PNG 压缩，尺寸为 384 × 384，总大小约 445 KB，保留插画内容。

背景均为浅薄荷绿，主体正面，无文字、品牌或外部人物照片。项目使用时可按展示尺寸进行无内容变化的压缩与缩放。
