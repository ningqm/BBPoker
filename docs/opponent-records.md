# 个人牌谱与对手战绩

个人牌谱只统计本人实际获发底牌且已结束的手牌。旁观记录不进入个人战绩；桌内查看仍按原有成员权限进行。所有筛选条件同时满足，最近手数在其他条件筛选后取最新若干手，最后才分页。列表与汇总基于同一批手牌，翻页不改变汇总。

## 筛选口径

- 对手按稳定账号 ID 识别，改昵称不会拆成两个人；候选只来自与本人共同获发底牌的历史手牌。
- 位置按每手归档时的实际发牌人数、座位、庄位及大小盲位计算，不按当前房间人数。单挑庄家兼小盲，BTN 与 SB 均可筛中，展示为 BTN/SB。补交大盲不会改变位置。
- 翻后单挑指本人未弃牌、进入第一个完整翻牌时恰好还有两人；多人池指三人及以上。三人看翻牌后再变为单挑，仍属于多人池。
- “我未见翻牌”包含本人翻前弃牌，以及整手翻前结束；其他人看到翻牌不会改变本人分类。补看牌不算翻牌，翻前全下后正常跑出的翻牌算。
- 同时选择对手与翻后单挑／多人池时，本人和所选对手必须共同进入该翻牌。
- 桌上人数按这一手实际发牌人数：两人、3–6 人、7–9 人。
- 旧记录不能可靠还原的字段显示未知。炸弹池不收大小盲，因此只标记可确定的庄位，其他位置不伪造盲位。

## 盈亏口径

牌谱原有“我的整手盈亏”筛选及总计包含本手小游戏记账。对手战绩仅统计德州和炸弹底池的净积分，排除鱿鱼等小游戏；没有把一轮鱿鱼结算归给某个对手。

**同手盈亏**是“我与此人共同获发底牌的这些手牌里，我的整手德州净盈亏”。**翻后单挑盈亏**是其中我与此人两人进入翻牌的那些手牌的同一净盈亏口径。它们均不表示从该对手直接赢得的金额：翻后单挑也可能有其他人在翻前贡献的积分。

例如我本手赢 10BB，对手输 8BB，第三人翻前弃掉 2BB：我的这手盈亏是 +10BB，不能声称从该对手赢了 10BB。

一手多人牌会出现在多个对手行内，各行不能相加。报告总体只按唯一手牌计算一次。赢／输／持平手数按对应的德州净盈亏判断。

BB 盈亏逐手以归档的大盲折算后累加，不能先合计不同盲级的积分再除一个大盲。缺失有效大盲的旧记录保留积分盈亏，但不混入 BB 数，并显示覆盖手数。正负颜色只辅助阅读，金额保留正负号。

统计不需要读取对手未公开底牌、未发出的牌或洗牌种子，也不修改历史档案。
