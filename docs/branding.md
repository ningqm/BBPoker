# BBPoker · 品牌约定

产品统一称为 **BBPoker**，包括网页、邀请、牌谱导出、PWA 和后续客户端。历史验收记录中的旧名称保留，不能当成当前品牌。

- 暖白浅色界面、深绿色牌桌与操作重点，正文使用深色高对比文字。
- 0.5.0 图标为双 B 手牌：薄荷绿后牌、暖白前牌与珊瑚色方块角标。图标由本项目独立绘制，不使用竞品商标、图片、表情包或音效。
- 大厅聚焦创建、加入和当前牌桌；导航包括牌桌、牌谱、生涯。不加大幅标语；头像选择放在账号资料里，注册不增加必填步骤。
- 聊天默认收起，表情短暂显示在座位旁并可关闭。发牌、行动和结算动效辅助识别状态，尊重系统减少动态效果设置。
- 历史牌谱只包含本人底牌及最终公开的牌；无法证明亮牌时点的旧记录只在结果帧显示对手公开牌。
- 应用 ID、内部存储目录、环境变量、协议字段与身份键保留，避免换名称后丢失身份。导出验证器继续接受旧版文件，PHH 的 `_tongzhuo_*` 扩展保持兼容。
- 随机洗牌采用密码学随机源，可见牌承诺校验不是第三方认证，也不保证胜率或避免反超。

此次公开包含完整网页实现和测试所需的少量实验性桥接代码，不包含原生平台工程、签名资料或安装包。
