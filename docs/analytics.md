# 个人数据与全下跑牌

BBPoker v0.9 的统计入口同时放在个人页和牌桌内。牌桌内打开弹窗查看自己的数据，不离开正在玩的桌。所有统计只包含已经结算、本人实际拿到牌的手；旁观不增加手数，正在进行的手不会提前计入盈亏。

## 指标口径

每个百分比同时提供分子和分母。分母为 0 显示“— / 暂无机会”，不会伪装成 0% 的结论。小样本只是记录，不用标签断言玩家强弱。

| 指标 | 分子 / 分母 |
| --- | --- |
| 盈利手率 | 德州净收益大于 0 的手数 / 已结算手数；小游戏不影响判定 |
| VPIP 主动入池 | 翻前主动跟注、加注或全下投入积分的手数 / 普通德州手数 |
| PFR 翻前加注 | 翻前至少加注一次的手数 / 普通德州手数 |
| RFI 率先加注 | 此前无人主动入池且自己加注的手数 / 无人主动入池时可合法加注的手数 |
| 3B 再加注 | 面对一轮加注再次加注的手数 / 面对一轮加注时可合法再加注的手数 |
| 4B 四次下注 | 面对两轮加注继续加注的手数 / 此时可合法再加注的手数 |
| 5B 五次下注 | 面对三轮加注继续加注的手数 / 此时可合法再加注的手数 |
| 看翻牌率 | 翻牌发出时尚未弃牌的手数 / 已结算手数 |
| WTSD 摊牌率 | 参与最终摊牌的手数 / 看过翻牌的手数 |
| W$SD 摊牌赢池率 | 摊牌时赢得任一底池的手数 / 参与摊牌的手数；包括平分池及边池，不等同于整手净盈利 |
| BB/100 | 每手德州净收益除以该手大盲后求和，再除以样本手数乘 100 |

普通德州手数包含盲注直接获胜、强制盲注用尽积分的手，排除没有翻前行动阶段的炸弹池；这些强制投入不算 VPIP。这个分母沿用 BBPoker 历史统计，避免升级后同一批旧牌谱的 VPIP 突然变化。其他软件可能排除无需行动的手，比较时应先核对口径。

3B/4B/5B 的分母是相应的机会次数，不是全部手数；同一手同一指标最多记一次。短码全下有可能提高跟注价格却未重新开放此前行动者的加注权，不给该行动者增加再加注机会。多次短码全下累积满足重新开放条件时，才记录新的机会。RFI 不把有人溜入后的隔离加注算作率先开池。

所有德州收益包含对应手的炸弹池输赢；小游戏净额另列。带入与补入不当成亏损。按日期统计时，旧版本存在的散桌蘑菇退款按真实发生时间记入小游戏收益；“最近 N 手”模式只统计选中的手，因此不包含无法归属单手的场外退款。

0.11 起鱿鱼轮按独立结算流水记账，按实际结算时间计入小游戏，即使玩家在结算前已经离桌。手内回放所示的同笔鱿鱼金额不重复累计；旧牌谱保留原口径。独立结算不增加手数、VPIP 等机会或全下 EV。“最近 N 手”只纳入选中手关联的鱿鱼结算，排除手外结算，并在界面提示。

## 全下胜率和跑牌偏差

只有至少两家仍有赢池资格、后续无人需要再作下注决定且公共牌尚未发齐时，才固定全下计算起点。仍有两家可以继续争夺边池时，不提前摊开其他人的底牌或发布利用未公开底牌算出的胜率。河牌后的全下已没有待发公共牌，不属于跑牌样本。

每个新公共牌阶段揭开后，画面按当前可见牌重新计算：翻牌三张一起更新，然后分别更新转牌与河牌。胜率包含平分底池的份额；多人及不同筹码量按每个底池的资格分别计算。展示方式区分精确枚举与抽样估计，不把抽样小数当成无误差的真值。用于展示和统计的计算不控制发牌，也不改变已经固定的牌堆。

“跑牌期望净盈利”采用停止下注时固定的第一次计算结果，不能随着后续发牌而重置。每手期望净额 = 各底池期望分得积分之和 − 该手实际投入积分（已经退回的无人跟注部分除外）。实际净额来自最终德州结算；“跑牌偏差” = 实际净额 − 起点期望净额，不含鱿鱼、退款等小游戏收支。

例如两人各投入 100 积分，起点权益为 80%，期望净额约为 `200 × 80% − 100 = +60`。最终输掉整池，实际净额为 `−100`，跑牌偏差为 `−160`。这是这批全下牌跑出结果与数学期望的差距，不代表下一手会补偿，也不是对洗牌公平性的检验。

旧牌谱仍能统计手数、输赢和行动指标。没有保存全下起点及当时计算结果的旧牌谱，明确记为“缺少全下数据”；不使用最终公共牌倒推或补写虚构期望。总额、曲线和明细只汇总同一批有完整起点记录的手，同时显示覆盖数量。记录中保留隐私限制，不返回未公开底牌、整副牌或密钥。

## 筛选和接口

`GET /api/stats` 始终读取当前登录人的数据，不支持按任意用户 ID 查询他人的生涯。可传 `room`（服务层另验成员资格）、`from` / `to`（含边界的日期或带时区 ISO 时间）、`maxHands`（1–100000）。先按时间和牌桌过滤，再取最新 N 手。界面的近 1 / 3 / 7 / 30 天按用户设备日历生成边界；接口也接受互斥的 `period=1|3|7|30|all` 滚动天数方式。

`metrics` 的每项返回 `{count, opportunities, percent}`。收益曲线最多 200 点并保留首尾，汇总基于完整样本；全下明细显示最近 50 手。`allIn.count` 是具备期望记录的手数，`eligibleCount` 包含检测到但没有起点计算记录的历史全下手。无有效全下样本时，期望、实际和偏差返回 `null`。

## 牌桌内查看其他玩家

点击玩家头像可查看“本桌数据”或“累计数据”的核心统计。只计已经结算、且目标玩家实际获发两张底牌的手，不计正在进行的手，也不计仅旁观的手。“本桌数据”包含目标玩家在当前桌参与的手；“累计数据”包含目标玩家在所有桌参与的历史手，不要求查看者也参与，因此也包含目标玩家与其他人打过的牌。

返回手数、盈利手比例、VPIP、PFR、RFI、3B/4B/5B、WTSD、W$SD，以及每项的次数、机会数。无样本时为 `null`，界面显示“—”，不假装 0%。指标定义与上表一致；不返回他人底牌、行动日志、牌谱编号、盈亏曲线、他人与其他人交手的全下 EV 或登录账号信息。

接口：`GET /api/rooms/:code/players/:id/stats?scope=table|career`，默认 `table`。两种范围都要求查看者和目标玩家是当前房间成员，未取得邀请加入资格的人不能借此查询玩家数据。旧的试验范围 `shared` 返回 400；累计范围只扩大汇总样本，不扩大牌谱、底牌或账号字段的访问权限。


## 与我对抗

选手卡新增 `versus`，只包含查看者与此选手**双方实际获牌、已经结算**的共同手牌。“本桌数据”取本桌；“累计数据”取所有桌。查看自己的头像时 `versus=null`。旁观者仍可看公开核心指标，但自己没有参加过的手不会进入对抗统计。

默认展示翻后单挑手数、查看者在这些手的整手德州净盈亏（BB）、盈利手率及二人最终摊牌胜／负／平。单挑以第一个真实翻牌当时的两位未弃牌玩家为准，翻前全下跑出的翻牌也算；三人看翻牌后有人弃牌不能变成单挑样本，补看牌不算。德州净额不含带入、鱿鱼或其他小游戏，可能包含第三人此前投入的死钱，**不是从该对手直接赢得的金额**。

摊牌胜负要求最终恰好两位未弃牌者且共同争夺至少一个底池，比较归档底池的 `eligibleIds/winnerIds`，不比较总派彩或整手盈亏。单方边池不能覆盖共同底池胜负；两人平分共同底池记平；三人摊牌即使另有二人边池也不列为二人摊牌。

展开指标：

- 双向面对下注：所有共同手牌内，在行动当时恰好只剩双方未弃牌（含已全下的对手）、当前需跟价格由对方主动下注／加注设定时，记录弃牌、跟注、加注次数。包含翻前与翻后，分母是决策次数，不是手数；仍有第三人未弃牌的阶段不算，第三人弃牌后后续二人决策可计入。强制盲注与过牌不算；第三人加价后不再归给之前的加注者；短码全下跟注记跟、短码合法加价记加注。
- 双向 3-Bet：面对对方翻前首轮主动加注且尚无任何人再次加价，本人具备合法加价机会时计分母，再加价时计分子。包括溜入后的首轮隔离加注；没有重新开放加注权、筹码不足以加价、无人可回应加价时不计机会。采用引擎同一套合法行动规则。
- 二人 All-in 运势：停止下注时恰好两位未弃牌者、公共牌不足五张且保留第一次 EV 快照的手，汇总查看者实际与期望整手德州净额及差值。按每手当时的大盲折算，显示样本数与抽样估计数；河牌已发齐、三人锁定、其他人交手的记录均不包含。缺失或与起点公共牌不匹配的快照不补算。

`coverage` 明确报告无法可靠重建翻牌人数、行动、摊牌、全下资格的旧记录数。行动日志用公开的固定虚拟牌堆经同一规则引擎重放，只比较公共下注事件，不读取归档私牌或牌堆、不重新判断真实胜者；日志不完整或非法时整手行动指标不入样本。没有机会的百分比是 `null`。缺失历史大盲或净额时 BB 合计为 `null` 并提供覆盖数，不能以部分合计冒充完整统计。原始牌谱、底牌与私密账号字段不进入返回值。
