# 实验性客户端桥接代码

当前可完整运行和部署的产品是仓库根目录的网页与 Node.js 服务。

这里仅公开自动测试所需的桌面身份存储、隔离桥接和移动导出辅助代码。`scripts/build-clients.mjs` 同时保留用于测试客户端资源边界的构建逻辑；手机桥接打包仍需要未包含在此目录的完整移动工程与依赖。

此目录不是完整的 Electron/Capacitor App 工程，没有原生 package.json、依赖锁文件、签名资料、iOS/Android 项目或安装包。不要直接据此声称支持已发布的原生 App；不要单独运行这些桥接文件。默认 `npm test` 只读取或隔离执行所需代码，不要求安装 Electron、Capacitor 或移动 SDK。

原生应用的完整开发、打包和真机验收不属于此次公开范围。
