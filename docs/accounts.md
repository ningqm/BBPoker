# 账号与登录

当前使用账号密码，不需要申请短信或邮箱服务。本仓库源码版本见 package.json；线上运行版本需要另行核验。

## 分配账号（0.24.0 已上线）

公开注册已从界面和服务端关闭。已有账号、旧昵称身份及其积分、牌谱继续保留；部署该版本不会批量停用任何已有玩家。登录账号与牌桌昵称独立，昵称修改不改变账号权限、统计或记录。

- 被指定的管理员使用自己的账号正常打牌，头像菜单额外显示「账号管理」。普通玩家没有此入口，服务器也拒绝普通玩家直接调用管理接口。
- 管理员点「分配新账号」，填写登录账号及可选昵称；系统生成随机初始密码。账号为 3–24 位字母、数字或下划线，不区分大小写。
- 初始密码仅在本次创建结果中显示，可主动复制后私下交给朋友；关闭弹窗或切换身份即清空。管理员不能查询任何人的原密码。
- 朋友用分配的账号密码登录，可以修改自己的昵称、头像及密码。密码为 6–128 位字符；登录界面不再展示旧昵称恢复或忘记密码入口。
- 忘记密码请联系管理员重置。重置会撤销旧密码、旧找回码和全部已登录设备，不改变积分和牌谱。
- 停用账号会撤销会话、阻止登录及找回；不删历史，也不修改正在进行的牌局输赢。该玩家按正常断线规则处理。重新启用后必须重新登录，旧令牌不能复活。管理员不能在网页停用自己。
- 旧昵称身份仍可在原设备使用和恢复。需要账号密码时，由管理员找到原身份并选择「分配登录账号」；保留原用户 ID 和全部记录。原身份恢复码在此迁移后失效。

管理能力只授予维护者明确指定的唯一账号；网页分配的新账号始终是普通玩家。网页没有授予管理员、改分、查看他人未公开底牌的管理功能。账号管理并不能阻止朋友主动共享自己的账号密码；发现共享时可以重置或停用。

## 首次指定管理员（维护者操作）

`ADMIN_USER_IDS` 由服务器的私有配置指定稳定用户 ID；留空时无人可以管理账号。不能填写昵称或根据“第一个注册的人”自动授权。更改昵称、修改密码、换设备不会丢失管理资格。

正式发布前核对持有者的**登录账号**，用 `deploy/configure-account-admin.mjs` 从已有加密存档解析其唯一 ID，生成一个权限为 0600 的新配置文件。该工具只读存档，不创建身份、不修改密码/牌谱，不覆盖原配置、不重启服务；找不到账号、账号停用、已有不同管理员或输出已存在时拒绝操作。

```sh
node deploy/configure-account-admin.mjs \
  --data-dir /var/lib/bbpoker \
  --env-file /etc/bbpoker/app.env \
  --output /etc/bbpoker/app.env.assigned-new \
  --username EXISTING_LOGIN_NAME
```

以上是维护示例，必须替换为确认后的已有登录账号。先备份原私有配置，在无进行中牌局且获准发布时应用新配置并重启；登录后验证本人可管理也可打牌、其他账号无管理权限，再开放正常使用。配置、真实用户 ID 和凭据不得进入公开源码或截图。

如果持有者选择新账号，维护者可用 `deploy/prepare-new-admin.mjs --username LOGIN_NAME --output /私有目录/new-admin.json` 在交互终端不回显输入密码。输出仅含密码哈希和待授权 ID，不会创建线上账号或改变配置，必须保存在源码目录之外。正式获准发布后，在停止写入并完成备份的维护窗口核对登录名未占用，再创建该独立账号并绑定管理员配置；旧账号及历史不合并、不删除。全新空数据目录没有默认管理员或默认密码，不得为安装方便重新开放公开注册。

## 修改资料

右上角头像进入“我的账号”，可修改昵称、换一个 AI 默认头像，或上传 JPEG、PNG、WebP 图片并裁剪为头像。默认头像来自 6 张预先生成的原创动物插画，分配账号时随机选择，不会为每个新账号实时调用模型。昵称为 1–18 个字符；账号登录名不变，积分与牌谱归属不变。新资料会同步给当前桌的其他成员；已经保存的牌谱和聊天保留当时的名字。

## 数据与会话

密码不明文保存，使用独立随机盐和异步 scrypt（N=131072，r=8，p=1）计算哈希；计算并发和等待队列有上限，避免阻塞牌局。登录令牌和找回码以 SHA-256 哈希保存，与账号、牌谱一起存入现有 AES-256-GCM 加密存档。浏览器只记住登录令牌，不保存密码；新找回码及管理员生成的初始密码仅在生成时显示。

密码账号会话有效期为 30 天，每个账号最多保留 10 个会话。退出会撤销当前令牌；改密码、找回、旧身份绑定会撤销旧会话，也会结束对应的牌桌事件流。请求在异步处理后再次检查授权，避免已撤销会话继续写入。登录及找回限制单 IP 和单账号的尝试次数。

历史记录按稳定用户 ID 关联，绑定账号不复制或重建身份。旧昵称接口不再创建身份；保留旧恢复入口供已有身份使用，登录账号迁移由管理员完成。找回码验证成功后轮换，不能重复使用。上线过程不得覆盖原数据和密钥。

这不是手机实名或手机号验证系统。浏览器和服务器仍须保持可信；当前网页使用本地浏览器存储保留会话，未改成 HttpOnly Cookie。HTTPS、脚本来源限制与权限检查已保留，但这些不能保证被入侵的设备或服务器安全。

## 自定义头像

浏览器只上传裁剪后的 256 × 256 PNG 缩略图，服务端验证并重新编码，去除附带的照片元数据。图片以加密文件保存在数据目录的 `avatars/` 下，用户资料仅记录头像编号；登录并与头像主人同桌的成员才能读取，主人也能读取自己的头像。接口禁止缓存，退出登录会清除页面里的头像缓存。用户上传内容不进入公开源码或发布包。

备份时需要同时保留 `table.enc`、`key` 和 `avatars/`。程序更新不清除该目录；服务器磁盘丢失仍需要独立备份恢复。
