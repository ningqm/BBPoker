# 战绩、个人牌谱与对手盈亏

主导航为「牌桌 / 战绩」。战绩中的「概览 / 对局 / 牌谱 / 对手」是并列栏目；桌内牌谱仍只查看当前桌。对手页不再嵌套在牌谱内。

## 牌谱筛选

个人牌谱只统计本人实际获发底牌且已完成的手牌。旁观记录不进入个人战绩；桌内观察者仍按成员权限查看本桌记录。全部筛选同时满足，最近手数在其他条件之后、分页之前应用。翻页不会改变汇总范围。

- 结果：盈利、亏损、赢超过 N BB、输超过 N BB。移除持平和手牌序号搜索；旧 API 参数仅保留兼容。
- 发牌方式与鱿鱼玩法独立选择：普通发牌 / 炸弹池 × 无鱿鱼 / 普通鱿鱼 / 无限鱿鱼。按每手冻结的轮次快照判断，不使用当前房间开关。
- 对手按稳定账号 ID；改昵称不拆分。与该对手的共同牌谱仍显示整手结果，不等于两人之间的直接金额。
- 人数可精确选 2–9 人，指这一手实际获牌人数，不是座位上限。位置用中文与缩写：四人 CO/BTN/SB/BB；五人 HJ/CO/BTN/SB/BB。CO=庄前一位，HJ=庄前两位；六人首位这里称 UTG，其他教学体系也称 LJ，不能忽略人数将所有 UTG 混作同一相对位置。
- 双人庄家兼小盲，BTN 与 SB 均可筛中。补交大盲不改变自然位置；炸弹池只标庄位，其余标「炸弹池无盲位」，不伪造大小盲。
- 翻后单挑 / 多人池以第一个真实翻牌当时仍在牌中的人数计算，且本人必须仍在牌中。三人翻牌后再变二人仍为多人池。正常全下跑牌算，结算后补看不算。若同时选对手，该对手也必须在该翻牌中。
- 常用起手牌：口袋对子、大对子、同花连张、杂色连张、同花隔张、同花 A、两张大牌、固定顶端 AA/KK/QQ/AK。两张牌的点数和花色可分别选填。连张按 23–AK 定义，不含 A2；杂色是不同花色，不是必须一红一黑。

## 两人直接盈亏

新 `/api/opponents` 按日期、对局和对手筛选，独立于牌谱起手牌/位置等手级筛选。正数表示我净赢、负数表示我净输；展示从对方赢得、输给对方、净额，分别列出德州和鱿鱼。不包含带入、补码和提现式现金概念。

德州对每层主池/边池重建各人的投入，按归档派奖先扣回该人在本池的投入，得到本池净赢者/净输者。每名净输者的损失按本池各净赢者的净盈利比例分配。奇数筹码按真实赢家顺序处理，未跟注退款不记作赢来，死小盲在主池单独计算。与引擎的每池金额、资格、派奖、每人最终筹码净额全部核对；不一致则标资料不足。

例子：

- 三人各投 100，A 独赢：B→A 100，C→A 100。
- 三人各投 100，A/B 平分：C→A 50，C→B 50，A/B 之间为 0。
- A/B/C 投 100/200/200，A 赢主池、B 赢边池：B→A 100，C→A 100，C→B 100。B 本手总盈亏虽为 0，但对 A 净输 100、对 C 净赢 100。

多人分池没有记录逐枚筹码的去向，这是明确的按底池分摊约定，不能声称存在唯一物理转账路径。内部用精确分数计算，最后才转换展示；各对手净额可相加，合计只计一遍。

鱿鱼依据完整结算流水和本轮冻结名单、最终鱼数、实际单价重建无鱼者向每名持鱼者的支付。普通/无限模式、多人受罚、已离桌/缺席成员均按整轮计算，不取最后一手的发牌名单。按结算时间筛日期，与德州按手牌时间分开；流水与手牌中的镜像不会重复计入。

旧记录缺失、冲突或无法证明完整名单时，相关金额显示「—」，不把可核对的一部分当完整合计。缺失流水的已知结算不能被误当零。旧小游戏不属于可还原的德州/鱿鱼归属时单独提示未计入。历史大盲逐手/逐轮换算，缺失大盲不拿当前房间配置代替。

统计只使用结算数据和公开头像昵称，不读取底牌、牌堆、随机种子、账号密码。新查询不会修改历史数据；新鱿鱼结算补存冻结参与名单、单价与结算时刻以利复核。原 `/api/hands` 中旧同桌汇总保留兼容，但新对手页不会使用它。

## 桌内选手卡的对抗摘要

选手头像中的“与我对抗”继续使用首次真实翻牌的单挑口径（与新对手页的逐底池直接金额不同），并随“本桌／累计”切换统计范围。主卡显示单挑手数、这些手里我的整手德州净 BB、盈利手率、二人最终摊牌胜负平；展开可看双向面对下注的反应、针对彼此翻前首轮加注的 3-Bet 机会，以及仅两人锁定时的全下实际／期望差值。

这里的反应次数要求决策时恰好只剩双方未弃牌，3-Bet 机会则也包含双方参与的多人翻前手；两者不能与“翻后单挑手数”混作同一个分母。摊牌比较共同争夺的底池赢家；不会把边池多拿积分误判为战胜主池赢家。对抗数据只呈现当前查看者亲自参与的共同手牌，不因目标玩家选择“累计”而泄露他与其他人的私人战绩。详细分母、历史缺失覆盖与隐私规则见 [统计说明](analytics.md#与我对抗)。
